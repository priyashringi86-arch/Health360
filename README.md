Healthcare Analysis Dashboard

An interactive healthcare analytics project built using Tableau Public.

Project Overview

This project explores healthcare risk factors and heart disease patterns using patient data from a CSV dataset. It presents interactive visualizations to understand relationships between patient characteristics and heart disease.

Key Visualizations

- Patient Distribution by Age Group
- Exercise Level Distribution
- Gender-wise Health Risk Score
- Blood Pressure Analysis by Age
- Heart Disease Distribution by Age Group
- Average Heart Disease by Age Group
- BMI vs Heart Disease by Age Group

Tools & Technologies

- Tableau Public
- CSV Dataset
- Data Visualization
- Exploratory Data Analysis

Dataset

Dataset Name: "smart_healthcare_dataset.csv"
